# WAKUWAKU Company Profile

Static company-profile website built with vanilla HTML, CSS, and JavaScript.

## Run locally

```powershell
py -m http.server 8765 --bind 127.0.0.1
```

Open `http://127.0.0.1:8765/`.

The hero video and verified destinations are loaded from their existing public URLs. The WakuFlow artwork used by the page is stored in `reference-source/Waku CPN PF/`.
